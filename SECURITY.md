# Security reports

Report vulnerabilities and accidentally exposed credentials through
[GitHub's private vulnerability reporting](https://github.com/daintreehq/assistant-backend/security/advisories/new).
Do not put sensitive details in a public issue or attachment.

Include the affected component or endpoint, the impact, and minimal reproduction
steps with placeholders for secrets and personal data. Do not include live
credentials, private code or a full transcript. Test with resources you control.

If a credential has been exposed, revoke or rotate it at its provider. Removing a
file or editing a public report does not invalidate a credential.

This project tracks the current `develop` branch and the hosted service; there is
no separately maintained series of older backend releases.

Incorrect runbook selection, stuck workflows and missing procedures without a
security impact belong in the normal
[issue forms](https://github.com/daintreehq/assistant-backend/issues/new/choose).
